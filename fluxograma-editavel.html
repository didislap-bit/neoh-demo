Como preencher direto no fluxograma:
  • Clique em qualquer texto (título, descrição, nomes de raia/fase, ficha técnica) para editar — é como um documento normal.
  • Use os botões + tracejados para adicionar raia, fase ou atividade no cruzamento certo.
  • Em cada card: num. é a sequência (1,2,3…) — use ! para exceção e ★ para atividade transversal; o botão ◆ transforma o card em decisão (fica vermelho); os campos RN/E- são as tags de regra de negócio e exceção tratada; o campo abaixo do card é para os caminhos "Sim → / Não →" (só decisões precisam disso).
  • As tabelas abaixo do fluxograma (Regras de Negócio, Exceções, KPIs) também são editáveis célula a célula — use "+ adicionar linha".
  • Lembre-se de preencher a Ficha Técnica (Objetivo, Escopo, Evento inicial/final, Entradas/Saídas, Atores, Sistemas) — são os 14 elementos obrigatórios de todo fluxograma hospitalar.
  • Quando terminar, clique em "Baixar fluxograma (.html)" para gerar o arquivo final, limpo, pronto para o repositório.
